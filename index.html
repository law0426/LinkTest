hva er div?

hva gjør det? det er basically en container, som tar information fra eg. style.css og velger hvor det skal applyes. Den bruker class og id.
Hva er class og Id?
det er labels som html elmenter kan equippe for å kjennes igjen av andre elementer
class er generisk. id er specific. det bestemmer hvilken karakteristikker i hvilken gruppe overrider den andre under konflikt
